## Known limitations

- **WirePlumber missing in base composition (pre-existing):** the
  catalogue `desktop` package set has no `pipewire`/`pipewire-audio`/
  `wireplumber` (only the Studio set adds them), so Desktop and Gaming
  installs have pipewire core only and no audio session manager.
  `horneroctl gaming doctor` reports FAIL truthfully. Same composition
  lineage as preview22/23; catalogue fix tracked separately.
- **Installer copy bug:** the wizard describes Gaming choices with the
  Agents summary text ("Server-derived host for isolated autonomous-agent
  workloads") because the render script's fallback branch is used for
  Gaming. Installation is unaffected; fix tracked in installer.
- Gaming, Desktop and Studio are **Preview**, not Stable or Supported.
  Niri choices are Experimental. Calamares is provisional; Panda Foss
  owns the future official installer.
- VM evidence is not physical-hardware certification.
