## Notes from this run

- The live boot shows a `systemd-firstboot` timezone prompt on tty1;
  skipping it (Enter) lets the graphical Hornero Desktop session
  proceed, and the installed system boots straight to the greeter.
- `pipewire-pulse` reported inactive at check time (socket
  activation not exercised); PipeWire and WirePlumber were active
  and OBS saw the desktop audio source.

## Known limitations

- Desktop, Studio and Gaming are **Preview**. Niri is Experimental.
  Calamares is provisional; Panda Foss owns the future official
  installer.
- Encrypted swap remains honestly disabled in the partitioner
  (`userSwapChoices: [ none ]`); LUKS uses `luksGeneration: luks1`,
  LUKS2 unevaluated.
- Existing preview24/25/27 installs do not gain `ID=horneroos` from
  this release; the identity step runs only during installation.
  `horneroctl package upgrade` is a `pacman -Syu` wrapper: it does
  not update AUR packages, reconcile edition composition, or
  provide rollback.
- VM evidence is not physical-hardware certification.
