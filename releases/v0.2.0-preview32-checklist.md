## Root causes fixed by this release

- **No session polkit agent on fresh installs (#366).** The config
  autostarts polkit-gnome in Hyprland sessions, but the package was
  in no install set, so `pkexec` failed (exit 127, "No session for
  cookie") and graphical upgrades could not authenticate. The
  desktop catalogue now installs `polkit-gnome` (#367);
  `hornero-config` 0.3.18-1 hard-depends on it so existing
  installs gain the agent on their next package update
  (config#120) and spawns it in Niri sessions (config#119).
  Regression coverage: qa `recovery/polkit-agent` cell
  (HorneroOS/qa#60, #61).
- **`checkupdates` dependencies missing (#364).** The catalogue
  now ships `pacman-contrib` and `fakeroot`, so
  `horneroctl package status` works out of the box.
- **Unencrypted installs printed an initramfs encryption-mapping
  error on every boot (installer#88)**, recorded as a known
  cosmetic issue in the preview31 checklist. installer#89 anchors
  the HOOKS rewrite; this artifact's unencrypted boot journal has
  zero `encryption mapping` matches.
