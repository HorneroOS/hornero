## One-time workaround for preview22–25 installs (updates)

```bash
sudo sed -i '1i Server = https://geo.mirror.pkgbuild.com/$repo/os/$arch' /etc/pacman.d/mirrorlist
sudo sed -i 's/^\[multilib\]/[multilib]\nInclude = \/etc\/pacman.d\/mirrorlist/' /etc/pacman.conf
sudo pacman -Syu
```

installer#47 (merged) makes fresh installs do this automatically. Do
not upgrade Hyprland past 0.56 on hornero-config 0.3.11 systems without
also updating hornero-config from AUR.

## Known limitations

- Desktop, Studio and Gaming are **Preview**. Niri is Experimental.
  Calamares is provisional; Panda Foss owns the future official
  installer.
- The installer still defaults to `copytoram` behaviour that can break
  `unpackfs` on high-RAM machines, and encrypted swap can generate an
  initramfs referencing the missing `openswap` hook. Both are P0 for
  the next preview; use `copytoram=n` and No Swap until then.
- LUKS uses `luksGeneration: luks1`; LUKS2 is unevaluated.
- VM evidence is not physical-hardware certification.
